Make it yours, keep it safe

How the app nudges you A browser-only library isn't an error — the Safety state reads Action needed, and its button is Save to disk. Click it, pick a folder, and from then on Archie mirrors every change there.

Your own exhibitsaved & yours

Open an Example and you're exploring a template — a banner reminds you edits here aren't saved. "Keep a copy" turns it into an exhibit you own, saved wherever your library is bound.

Under the hood Browser storage is OPFS; "Save to disk" uses a real folder (File System Access on Chromium) or a .archie.zip elsewhere. On disk it's plain JSON plus media — Git-friendly. The same zip is the unit of async collaboration: share a copy, import changes back, merged by version history.
Try it On the Library home, click Save to disk and pick a folder. From then on it autosaves there — reopen anytime with Open a library….
