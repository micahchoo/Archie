Share it — the easy way first

Publish opens one surface that first asks where to send it — the web, a local folder, or a portable file. Start with the portable file: no account, no server, nothing to configure. Whoever you send it to opens it and reads.

Use it to back up your work, move between machines, or hand a finished exhibit to a colleague.

Also the collaboration unit The same .archie.zip is how two people work async: share a copy, each edits, then import the changes back — Archie merges them by version history. No server, no accounts.

Or put it live on the web

To put a public site online, pick Publish to the web and connect GitHub — the whole wizard runs right there in the same surface. Hit Continue with GitHub: Archie shows a one-time code, you open GitHub and enter it to authorize — no token to generate, paste, or store. It then uploads your media, makes the commit, turns Pages on, and hands you a live URL. Step away mid-sign-in (Esc) and you resume on the same code later; if a code expires, just start again.

For citation & reuse You can include your full-resolution originals so others can cite them. Links between exhibits in your library are checked as you publish, so nothing points into the void. (Prefer a token? A personal-access-token form is still there as an advanced option.)
