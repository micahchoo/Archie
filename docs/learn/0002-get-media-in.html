Get your media in

The slow way is to start blank and add files one by one. Three onramps fill an Exhibit — two of them save real time.

Start empty Media folder IIIF link
→
Your Exhibitmedia in, in order
Where it lives On the Studio Library home, the dashed "+ New exhibit" tile opens one dialog — pick Start empty, From a media folder, or From a IIIF link. The two folder/IIIF choices are the ones people miss.

The two you'd miss

Start empty The obvious one. Opens an empty exhibit; you add media as you go.
From a media foldereasy to miss Point at a folder and every image, audio, or video file becomes an Object, kept in the folder's order — one gesture builds the whole exhibit. Subfolders can each become their own exhibit, and the title comes prefilled from the folder's name (edit it before you create).
From a IIIF linkeasy to miss Paste a IIIF manifest URL from a library or museum — Archie validates it as you paste, then its images flow straight in, already captioned.

Already inside an exhibit? The same dialog returns as "+ Add media" (in the editor) or the Add media plate (on the overview) — same folder and IIIF paths, plus A map for a geographic basemap.

For the standards-minded The IIIF onramp bootstraps from any institutional manifest — tens of thousands are published by libraries and museums, so you can annotate a source collection without downloading a thing. A folder import keeps each file's original name as provenance, so your Objects stay citable back to source.
Try it In Studio, click the dashed "+ New exhibit" tile and choose "From a media folder." Watch a whole Exhibit appear, each file already an Object in order.
