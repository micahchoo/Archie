# BAKE-INDEX — Issue 20 execution ledger (images.json misses carried exhibits)

The merge-preserving bake (`apps/viewer/scripts/gen-published.mts`, Archie-9b93) rewrites the tree
as a UNION: it regenerates the exhibits its SOURCE owns and CARRIES every other committed exhibit
untouched, re-merging the three root indexes (`exhibits.json` / `collection.json` / `index.html`)
over the carried set. But it writes the fourth library-global index, `images.json` (ADR-0023, the
Gallery all-images wall), straight from the **source-only** projection in the write loop
(`:137-143`) — never re-merged over carried exhibits. Result: a tree whose `exhibits.json` lists 8
exhibits but whose `images.json` indexes only the source's — the wall silently loses every carried
exhibit's images.
