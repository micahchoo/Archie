# Shape the story

A narrative guides visitors through an exhibit in a deliberate order. Each
**section** contains prose and refers to one media object. Its framing determines
the region or moment that the visitor sees.

To start a narrative:

1. Open the object that introduces your story.
2. Select **Add a section** in the narrative panel.
3. Enter the section title and text.
4. Set its framing on the object.
5. Add further sections on this object or another object.

The panel also offers a section from an existing note. This copies the note text
and framing into a new section. The section controls move sections up or down.

Sections make narrative the leading reading mode. Without sections, the media
objects determine the initial presentation. You do not need to select a narrative
template.

Three tools shape the experience:

- **Sections** set the order of a guided story.
- **Readings** group interpretations of the material.
- **Tags** filter notes by subject.

An exhibit can use any of these tools. A single annotated image is also a complete
exhibit.
