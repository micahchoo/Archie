The two halves of the File System API

HalfStatusMeaning
OPFS
navigator.storage.getDirectory()		 Baseline, widely available (Mar 2023) Private per-origin storage. No prompt. Optimised for in-place writes. Available in Workers.
Pickers
showDirectoryPicker · showOpenFilePicker · showSaveFilePicker		 Limited availability · experimental Real user files. Secure context + transient user activation required. Writes go via temp file + security checks — slower.

Picker failures unrelated to support

SymptomCause
Picker missing on a browser that has itNot a secure context — needs HTTPS or localhost. A LAN IP won't do.
SecurityError from a supported pickerTransient user activation expired — you awaited before calling. Open the picker first, do slow work after.
AbortErrorUser dismissed, or the browser judged the directory too sensitive.
