# Broken probes, preserved as evidence

These files are **not tests and are never run.** No build wiring points at them; nothing imports them.

They are the artifacts behind `.claude/rules/post-review-fixes-are-unreviewed.md` habit **1a** — *the
subject can be EMPTY, and the probe still prints a verdict*. Each one produced a confident sentence
about something it had not examined, and each is preserved so that rule's evidence is reproducible
rather than taken on faith.

If you are adding one: keep the broken form, say in the header what it PRINTED and what it had
ACTUALLY examined, and cite it from the rule.
