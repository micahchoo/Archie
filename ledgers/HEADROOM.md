## bakeTiles (ISSUES.md Direction 8)

`AObject.bakeTiles` is an opt-in per-object flag (Q-9) meaning "at publish, bake this object's REMOTE
source into a LOCAL Deep Zoom pyramid, so the published site deep-zooms from local tiles instead of a
slow / cross-origin IIIF service." The publish pipeline reads it and bakes accordingly, but nothing in
the persisted model or the Studio UI can turn it on.
