- `fs/seam.ts`: sequential awaited writes append chunks in order; a new writable replaces the file upon close. Captured buffers cannot change after a completed write.
- `fs/memory.ts`, `fs/zip.ts`, new internal `fs/buffered-writable.ts`: shared immutable chunk capture and one final concatenation; repeated writes now append consistently with FSA/ZipStream, with linear total copy cost.
- `fs/node.ts`, `fs/tauri.ts`: first Blob flushes prior buffered chunks before streaming; later string/ArrayBuffer chunks use that same handle. Both retain small-JSON buffering, streaming large Blobs, same-directory temp/rename commit, and cleanup on failed writes.
- `fs/hashing.ts`, `fs/zip-stream.ts`: buffer inputs captured by value; hashing now describes the shared append contract. Added mixed-byte/hash and streamed archive tests.
- `fs/conformance.ts`: common tests exercise repeated strings, mixed Blob/string/binary sequences in both orders, and input buffer mutation across Memory/Zip/Node/Tauri adapters.
